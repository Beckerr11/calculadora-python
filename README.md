# Calculator Python

Terminal calculator built with Python for quick arithmetic operations.

## Highlights

- Supports add, subtract, multiply, and divide
- Works in interactive mode or with CLI arguments
- Handles invalid numbers and division by zero
- Clear terminal output for fast testing

## Stack

- Python

## Run locally

Interactive mode:

```bash
python main.py
```

CLI mode:

```bash
python main.py --left 12 --right 4 --operation divide
```
